Option A: Quick List — Recommended

Habits in a scrollable grouped list with squircle icons. Tap any row to see a detail sheet with description and time selection inline. One interaction from browse to add.

Advantages
✓ Fully scannable — see all options at once, no card-by-card browsing
✓ One step — tap row → pick time → tap Add. No second modal layer.
✓ Familiar iOS pattern — list + detail sheet is the established standard
✓ Searchable — type to filter without needing to scroll
✓ Category chips — filter to a domain when the user knows what they want
✓ Nothing is lost — skipping doesn't remove items; list stays intact
Trade-offs
✗ Less gamified — no swipe gesture "reward" feel for exploratory discovery
✗ Dense with many habits — needs good filtering as the catalog grows

Recommended. Matches how users naturally browse. The swipe paradigm adds gesture friction without any corresponding benefit for this use case.

Tap any habit row on Phone 1 to open the inline detail sheet
