Option B: Category Grid

User first picks an area of life to improve, using warm tinted category cards. Then sees habits within that category and can select multiple at once. The goal-first framing changes the mental model from "what should I track?" to "what do I want to improve?"

Advantages
✓ Goal-oriented entry — "what do I want to improve" is the right question to start with
✓ Multi-select — add 2–3 related habits in a single flow
✓ Visual hierarchy — category-first reduces initial choice paralysis
✓ Warm tinted cards — each category has its own color identity, easy to recognize at a glance
Trade-offs
✗ 2 steps required — category → habits (vs Option A's direct browsable list)
✗ No time selection inline — defers the time-of-day setup to a later step
✗ Assumes category mental model — users searching for a specific habit must know its category first
Tap a category card to navigate to its habit list, then select habits to add
