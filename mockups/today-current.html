Today — Current (Cluttered)

The current Today screen piles XP bar, trial banner, progress ring, and insight card above the first habit. Users have to scroll past four unrelated widgets before they can do the one thing they came for: check off a habit.

What's Wrong
✗ Too much noise upfront — XP bar + trial + ring + insight card all appear before any habits
✗ First habit requires scrolling — on initial load the habit list is off-screen
✗ Competing CTAs — trial upgrade, insight dismiss, and FAB all fight for attention simultaneously
✗ XP gamification adds friction — complex level system without clear value for new users
✗ Progress ring buried in a card — loses visual weight, blends with other card widgets
What Works
✓ Time-grouped sections — morning/evening structure gives good temporal context
✓ Per-habit streaks — motivation visible inline next to each habit
✓ Progress ring concept — at-a-glance completion summary is valuable — just over-buried
